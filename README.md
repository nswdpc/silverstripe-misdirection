## Redirection module for Silverstripe framework

This module allows both simple and regular expression link redirections based on customisable mappings, either hooking into a page not found or replacing the default automated URL handling.

## Requirement

* Silverstripe Framework 5.4+

## Getting Started

Install the module using composer, after adding `https://github.com/nswdpc/silverstripe-misdirection.git` as a vcs repository to your project's composer.json:

```sh
composer require nglasl/silverstripe-misdirection
```
Then run dev/build?flush=1.
